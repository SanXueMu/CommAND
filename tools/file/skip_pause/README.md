# file.skip.pause — 跳过并暂停

刻意不处理的文件（本轮暂不支持的类型，如 PPT）走这个工具：**不报错、不产出**，而是抛
`ToolPauseError` → 任务落 `paused`、run 停在该步（审计 `step_paused`）。

## 为什么用「暂停」而不是「跳过/失败」

- **不是失败**：文件本身没问题，是本轮不处理 → 不该污染失败率、也不该触发重试
- **可见可决策**：任务清单里留下一条 `paused` 记录（附原因），用户可随时点「继续」
- **源文件不丢**：批次清单保证该文件以**原文件**形式随批次导出（导出目录结构与原结构一致）

## 入参

| 参数 | 说明 |
|---|---|
| `file` | 文件路径（记录用） |
| `reason` | 暂停原因，展示在任务清单与「继续」提示里 |
